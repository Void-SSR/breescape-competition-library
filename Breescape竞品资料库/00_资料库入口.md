## 使用方式

CSV 可用 Excel、WPS 或 Numbers 打开，按星级、规格、日期筛选，也可以搜索评论原文。文件采用 UTF-8 BOM 编码。商品 ID 与评论 ID 为长数字，导入表格时请将这两列设为文本，避免数字精度丢失。原始 CSV 中 ID 完整保留。

每行记录商品名称、商品 ID、原页链接、评论 ID（可获得时）、日期/时间、星级、规格、地区、原文、采样范围和来源文件。页面样本未提供评论 ID 的记录留空，并标明历史文件和行号。

## 筛选与排序口径

- 排除空白、纯表情、无信息量的泛评、明显不属于该商品的评论和无法理解的残缺文字。保留对触感、凉感、尺寸、耐用、洗护、材质、价格比较等具体体验；有明确内容的未收到货、错发、缺件、退款问题也保留。仅“好”“喜欢”“Great”等泛评不计入。
- 短评不一律排除：“Soft”“Not cooling”等虽短，但指向具体属性，予以保留。保留不代表已核实评论所述情况属实。
- 批量底稿先按评论 ID 合并，再按规范化原文去重；不同评论 ID 但正文相同也只保留一条。历史页面样本按规范化原文合并。原文不改写、不补写。
- 按已知发表日期从新到旧排列；精确时间为 UTC。仅有页面日期的记录标明时间精度，无法保证同日记录严格先后。

## 采样限制

**床单包含一星补充批次，负评被主动补充；不能用这份资料计算商品整体好评率或推算全体买家的问题发生率。** 它适合查找需求、产品体验、投诉情境与原文证据。褥垫合并原页面样本、外部推荐样本与最新排序的补采样本，也不是随机样本。
