## 复算范围

`adjudicate.py`调用`targeted_patch_v1_2.py`，从封存的v1.1提交快照重放本轮人工裁决，`reproduce.py`只对最终标签作去重、计数、比例和引文核验。两者不依据关键词或星级生成主题。复算不会读取或写入应用数据库。

在本目录运行：

```sh
python3 adjudicate.py
python3 reproduce.py
python3 verify_targeted_v1_2.py
```

不要把复算成功误解为语义判断绝对正确。语义部分仍依赖逐条人工判断；v1.1已作163条隐藏旧标签的同一分析者二读，本轮未重复；保留分歧和限制。v1.2只做限定范围的定向复核。主样本是928条便利样本；687条额外一星、13条推荐样本各自单列。
