**先读 `08_研究结论与机制修订建议.md`。** 它包含正式主样本TOP3、占比、购买与复购线索、竞争解释、反例和现有机制的修订建议。具体引文集中在 `07_关键证据与反例.md`。

## 复算范围

`adjudicate.py`只重放明文写下的人工裁决，`reproduce.py`只对最终标签作去重、计数、比例和引文核验。两者不依据关键词或星级生成主题。复算不会读取或写入应用数据库。

在本目录运行：

```sh
python3 adjudicate.py
python3 reproduce.py
```

不要把复算成功误解为语义判断绝对正确。语义部分仍依赖逐条人工判断；本次另作163条隐藏旧标签的同一分析者二读，保留分歧和限制。主样本是928条便利样本；687条额外一星、13条推荐样本各自单列。
