# 百亿爆品算法 \- 升级中

### **AI 推理二条原则**

**1、严格按照框架顺序推进。每一步基于当前事实、约束和已有阶段性判断，形成当下最佳结论，并作为下一步的待检验输入。下一步不重新发散，而是在新增约束下重新检验上一结论：成立则延续，部分成立则修正，不成立则淘汰。阶段性结论可以继承，但不能被当作必须成立的证明前提。始终坚持“事实与约束 → 判断”，禁止“先维护结论 → 再寻找理由”。**

**2、框架中的每个问题及其对应答案要求，既是分析步骤，也是该步骤的评价函数。回答必须优先满足题目本身设定的判断标准、边界和输出形式，不得擅自改用另一套更熟悉的逻辑替代。若认为题目之间存在冲突、信息不足或评价函数本身有问题，应先明确指出，再在原框架内给出最佳判断。**

## 三、长处算法

**继续遵守二条总规则:严格按照框架顺序推进，继承但不保护结论；问题本身就是评价函数。**

### 第一层：从企业端寻找长处

1、我们起步时是从哪做出突破的？这背后的能力是什么？

2、比起同行，有哪些事情我们总是做得特别好、很擅长？

3、做出过哪些有效的战术动作，驱动企业增长？

4、在哪些方面，我们有明显的优势和护城河？

5、我们的哪些优势，是消费者最容易感知到的？



### 第二层：从顾客端寻找优势

1. 顾客经常夸我们产品什么？最满意哪些方面？

2. 在众多选择中，顾客为什么选择我们的产品？

3. 顾客向别人推荐我们的产品时，通常会怎么介绍？

4. 在顾客心中，我们的产品有哪些特别的标签或认知？

5. 在哪些人群或场景中，顾客更偏爱我们的产品？





### 第三层：界定“尖刀优势”（最能解决顾客什么问题？）

综上所述：

1. 我们最擅长解决的顾客问题是什么？（尖刀优势）

2. 你的尖刀优势最擅长在哪层需求突破（黄金切口）

3. 把这个优势极致放大，你的产品将会做出什么升级？

3. 尖刀优势下切，你拥有什么增长机会？

4. 如果没有明显的长处，那哪一项能力未来有可能成长为你的独门绝技？
